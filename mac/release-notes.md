## 설치
DMG를 열고 **AI Watchdog**를 **Applications** 폴더로 끌어다 놓으세요. (이전 버전이 있으면 "대치"를 누르세요.)
처음 열 때 "확인되지 않은 개발자" 경고가 나오면 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**를 한 번 누르세요.

## 1.1.1에서 고친 것
- **Claude를 켜 두기만 해도 "AI가 일하는 중"으로 나오던 문제를 고쳤어요.**
  Claude 앱은 쉬고 있어도 작은 프로세스가 수십 개 떠 있는데, 예전에는 이걸 모두 더해서 판단했어요.
  이제는 프로그램 하나가 최근 10초 동안 꾸준히 바쁠 때만 "일하는 중"으로 봐요.
- Claude 앱이 혼자 돌리는 확인용 프로그램(git 등)은 "명령 실행 중"으로 세지 않아요.
- AI Watchdog가 두 개 동시에 켜지지 않아요. 새 버전을 켜면 옛 버전은 저절로 꺼져요.
- DMG를 열면 디스크에 앱 아이콘이 보여요.

## 1.1에서 생긴 것
창 위쪽 탭: **지킴이 · 시스템 · 팬 · 토큰**
- **시스템**: CPU·GPU·메모리·저장 공간·배터리·네트워크.
- **팬**: 팬 속도와 온도. 자동 / 고정 / 온도 따라를 골라 **적용**해요. (처음 한 번 관리자 암호로 도우미 설치, 앱이 꺼지면 15초 안에 팬은 자동으로 돌아가요.)
- **토큰**: Claude Code 기록으로 총 토큰, API 정가로 친 금액, 날짜별·모델별 사용량.

## 1.1에서 새로 생긴 것
창 위쪽에 탭이 생겼어요: **지킴이 · 시스템 · 팬 · 토큰**

- **시스템**: CPU(사용자·시스템·온도), GPU, 메모리, 저장 공간, 배터리(성능 최대치·충전 횟수·전력), 네트워크.
- **팬**: 팬 속도와 CPU·GPU·배터리 온도. 자동 / 고정 / 온도 따라(커브)를 골라 **적용**해요.
  팬 속도를 바꾸려면 처음 한 번 관리자 암호로 작은 도우미를 설치해야 해요. AI Watchdog가 꺼지거나 멈추면 15초 안에 팬은 자동으로 돌아가요.
- **토큰**: 이 Mac의 Claude Code 기록으로 총 토큰, API 정가로 친 금액, 날짜별 사용량, 모델별 사용량을 보여 줘요.

7개 언어(한국어·English·日本語·中文·Español·Tiếng Việt·ไทย) 모두 지원해요.
